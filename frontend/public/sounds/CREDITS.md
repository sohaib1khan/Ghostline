# Sounds

These tones were generated for Ghostline. They are original. No third-party samples are included.

| File | What it is | License |
| --- | --- | --- |
| `tick.wav` | Short quiet tick while a trace character is correct | Original |
| `correct.wav` | Two-note chime when a line passes | Original |
| `wrong.wav` | Soft low tone when a line misses | Original |
| `complete.wav` | Three-note tone when a lesson or game round finishes | Original |

Sound stays off until a learner turns it on in Preferences.
